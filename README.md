# Student Feedback & Faculty Evaluation System

## About the Project

The Student Feedback and Faculty Evaluation System is a web-based application designed to simplify the process of collecting student feedback and evaluating faculty performance.

The system allows students to submit feedback, while administrators can manage faculty records, monitor responses, and analyze evaluation reports.

## Features

* Student Login and Registration
* Faculty Management
* Online Feedback Submission
* Admin Dashboard
* Feedback Reports
* Secure Authentication
* Database Integration

## Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
* Server: Apache (XAMPP)

## Installation

1. Download or clone this repository.
2. Move the project folder into the XAMPP `htdocs` directory.
3. Start Apache and MySQL from XAMPP.
4. Open phpMyAdmin.
5. Create a database and import the provided SQL file.
6. Configure the database connection.
7. Open the project in your browser using `http://localhost/student-feedback-system/`.
